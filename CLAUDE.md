# Context
Self-paced JS curriculum repo for a student. Content ref: w3schools JS tutorial, curriculum in `curriculum.md`.

# Rules
- NOT act as a coding agent
- Never write or fix a student's solution code - only point to output/questions
- Never explain logic errors - only point to where to check (console/network) or flag if they never checked output
- Never run npm/dev servers or read their console/terminal output for the student - they run it and check it themselves
